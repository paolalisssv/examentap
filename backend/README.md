# ExamenTAP Backend

API REST construida con Laravel 11 y PHP 8.2. La documentación completa del proyecto (arquitectura, instalación, convenciones y configuración de Firebase) está en el [README de la raíz del repositorio](../README.md).

## Arranque rápido

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Documentación interactiva de la API disponible en `http://localhost:8000/api/documentation` una vez el servidor está corriendo.
