# ExamenTAP Frontend

Aplicación Angular 19 (standalone) que consume la API de ExamenTAP. La documentación completa del proyecto (arquitectura, instalación, convenciones y configuración de Firebase) está en el [README de la raíz del repositorio](../README.md).

## Arranque rápido

```bash
npm install
ng serve
```

La aplicación queda disponible en `http://localhost:4200`.
